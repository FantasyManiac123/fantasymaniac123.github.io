THEME.JSON
==========
Každý gamebook môže mať v book.json napríklad:

"theme": "theme.json"

Podporované presety:
- default
- mystic
- fantasy
- cyberpunk
- horror

Theme JSON môže meniť:
- light / dark farby
- typography
- layout
- background.pattern

Vlastný obrázkový vzor pozadia
-------------------------------
Do priečinka books/<id>/images/ vlož malý bezšvový obrázok (napríklad SVG
alebo WebP) a uveď iba jeho názov. `patternImage` sa použije vo svetlej téme,
`darkPatternImage` v tmavej. Obrázok sa opakuje; `patternSize` určuje veľkosť
jednej dlaždice.

"background": {
  "patternImage": "pattern-light.svg",
  "darkPatternImage": "pattern-dark.svg",
  "patternSize": "256px 256px",
  "fixed": true
}
